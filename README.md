# PDF Semantic Search Application

A Flask-based web application for semantic search over PDF documents using FAISS and Sentence Transformers.

## Features
- Upload PDF documents through web interface
- Semantic search across all uploaded documents
- Display results with relevance scores
- Multiple PDF file support
- Delete uploaded PDFs and associated data
- Real-time search results
